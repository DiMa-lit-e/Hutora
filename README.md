# Проект «Заброшенная Украина: Киев × Первомайск»

Каталог урочищ, хуторов, исчезнувших населённых пунктов, заброшенных и бывших промышленных/военных объектов в радиусе ориентировочно 30–40 км от **Киева** и **Первомайска (Николаевская область)**.

## Правила каталога

- Координаты не выдумываются: для каждой точки указывается источник.
- Приоритет: Wikimapia / Wikipedia / Wikimedia Commons / GeoNames / официальные географические справочники.
- Фотографии должны быть реальными. Нейросетевые изображения не используются.
- Если реального фото не найдено, в папке объекта оставляется `photos.txt` со статусом `не найдено`, а не фальшивая картинка.
- Для бывших военных и технических объектов не публикуются сведения, которых нет в открытых источниках.
- Точка на карте не означает разрешённый или безопасный доступ.

## Структура

- `Киев/` — объекты Киевской зоны
- `Первомайск/` — объекты Первомайской зоны
- `data/places.csv` — сводная база
- `data/README.md` — методика и источники
- `ФОТО/` — реальные найденные фотографии либо ссылки на них

## Название проекта

**Заброшенная Украина: Киев × Первомайск**
