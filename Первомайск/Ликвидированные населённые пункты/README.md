# Ликвидированные населённые пункты Первомайской зоны

В исторических списках Первомайского района указаны ликвидированные в 1970–1980-х годах населённые пункты: Верхняя Лозоватка, Илларионовка, Забары, Запорожье, Калиновка и Сметана.

Для Верхней Лозоватки и Илларионовки точные координаты в текущей проверенной выдаче не подтверждены. Поэтому координаты намеренно оставлены пустыми — точку «на глаз» не ставим.
